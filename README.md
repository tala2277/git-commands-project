# Git Commands and GitHub Learning

In this project I wrote about the Git commands I learned in the course and some things I learned while using GitHub.

Git Commands

git init  
This command is used to start a new Git repository in a folder. It makes Git start tracking the files in the project.

git clone  
This command is used to copy a repository from GitHub to my computer so I can work on it locally.

git add  
This command is used to add files to the staging area before committing them.

git show  
This command shows details about a commit and the changes that were made.

git commit  
This command saves the changes in the repository history.

git status  
This command shows the current state of the repository and the files that were changed.

git push  
This command sends my commits from my computer to GitHub.

git pull  
This command downloads the latest changes from the repository on GitHub.

git branch  
This command is used to create or view branches.

git checkout  
This command is used to switch between branches.

git merge  
This command is used to combine changes from one branch into another.

git log  
This command shows the commit history of the project.

git diff  
This command shows the differences between file versions.

git remote  
This command connects the local repository with the remote repository on GitHub.

git reset --hard HEAD  
This command resets the project to the last commit and removes the changes that were not committed.

GitHub Learning

During the course I learned how to create repositories on GitHub and upload my work. I also learned how to write a README file to explain the project. We learned about pull requests and how they are used to review and merge changes. I also learned about collaboration where multiple developers can work on the same project. Another thing we learned is fork which allows us to copy a repository and work on it. We also learned about licenses and how they explain how other people can use the project
